# 日陰計算の検証

`?debug=shade`は、推定日陰率の根拠を地図とJSONで確認し、現地写真との比較を準備する開発者向けモードである。通常画面には表示しない。

## 計算と方位角

SunCalcは太陽方位角を「南=0度、西が正」のラジアンで返す。日陰ナビでは`bearing = SunCalc azimuth + 180度`により北=0度・時計回りへ変換し、影方位角は`(太陽方位角 + 180) mod 360`とする。影長は`建物高(m) / tan(太陽高度)`で求め、高度3度未満は判定不能、最大250mとする。

入力建物はPLATEAUのEPSG:6697からEPSG:4326へ変換済み。影の移動は緯度経度の差分加算ではなく、地球半径6,371,000mを使う測地移動（方位角・距離からの移動先計算）で求める。250m以下の対象範囲での地球楕円体との差は現地検証の許容範囲内だが、測量用途には使わない。

## テストと現地比較

自動テストは方位角の北基準変換、359/1度の正規化、東/南/西に対する影方位、影長、250m上限、低高度・夜間、測地移動100m、ルートサンプル、影ポリゴン包含、JSON記録を対象にする。

広島駅南口、八丁堀、本通、原爆ドーム周辺、平和記念公園を選択し、9:00、12:00、15:00、17:00で同じ建物の基部・影先端・影方位を撮影して比較する。目安は影先端20m以内、方位10度以内。雲量、道路高低差、樹木、屋根、工事は別記録する。

## 記録と制限

検証JSONのコピー・保存は利用者の明示操作でのみ実行し、日時、タイムゾーン、経路、太陽値、日陰率、点数、PLATEAU年度、アプリ版、緯度経度、メモを含む。現在地は取得しない。街路樹、地形、アーケード、現地の通行状況は未反映。本通アーケードは一次情報未確認の検証用概略データとして、建物影と分けて扱う。
