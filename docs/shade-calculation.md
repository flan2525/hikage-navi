# 日陰推定の計算方法

この実証版は、徒歩経路を約8m間隔でサンプリングし、各点の到着予定時刻（標準歩行速度 1.25m/s）における太陽位置をSunCalcで計算する。建物フットプリントを、建物高さ÷太陽高度の正接で求めた長さだけ太陽と反対方向へ投影し、元の建物と投影形状の範囲にルート点が含まれると日陰と判定する。

`推定日陰率 = 日陰と判定された区間の距離 ÷ ルート全体の距離 × 100`

日没後は建物影を計算しない。現状の建物は表示・計算機構を検証する小規模な実証用サンプルであり、PLATEAU投入後に差し替える。街路樹、アーケード以外の屋根、地形、道路高低差、季節要因、工事、通行止め、現地の天候は未反映である。表示は熱中症や安全を保証しない。
