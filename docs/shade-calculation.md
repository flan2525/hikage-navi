# 日陰推定の計算方法

## 入力と座標

徒歩経路を約8m間隔に分割し、各点の到着予定時刻を標準歩行速度1.25m/sで算出する。太陽高度・方位角はSunCalcで各到着時刻・緯度経度ごとに計算する。建物はPLATEAU広島市2024年度のフットプリントと高さをEPSG:4326で使用する。影先端は緯度経度を単純加算せず、方位角と距離から移動先を求める測地移動で算出する。現地検証の詳細は[shade-validation.md](shade-validation.md)。

## 建物影

太陽高度を `a`、建物高を `h` とすると、影の長さは次で求める。

`L = h / tan(a)`

影は太陽方位角の反対方向へ投影する。元の建物ポリゴンと、各外周辺を投影してできる四角形を合わせ、ルート点がいずれかに含まれる場合を日陰と判定する。これにより、単純に元形状と移動後形状を連結するよりも任意形状のフットプリントを安全に扱える。

高度3度未満（日没後を含む）は日陰判定を行わず、影の長さは0とする。高度が低い時間帯の過大な影を避けるため、影の長さは250mで上限を設ける。地図上の半透明の影は出発時刻の太陽位置、ルートの色分けは各地点の到着時刻を反映する。

`推定日陰率 = 日陰と判定されたルート区間の距離 ÷ 建物データ範囲内の判定対象距離 × 100`

複数エリアでは、読み込んだPLATEAUデータセットのbbox外を`範囲外`として分類する。範囲外は日なたに含めず、日陰率の分子・分母から除外する。

## 前提と制限

- 高さは原則`measuredHeight`を使用する。未設定で建物形状のZ値から高低差を算出できる時だけ`geometry_z_range`として採用し、どちらも得られない建物は日陰計算から除外する。
- 街路樹、地形、道路高低差、屋根、季節、工事、通行止め、実際の天候は未反映である。本通アーケードはクールスポット用の別データであり、今回のPLATEAU建物影には含めない。
- 建物データは現地状況と異なる場合があり、暑さ・安全・熱中症の回避を保証しない。

既知条件（高さ10m・太陽高度45度で影長10m、太陽方位90度で影は西向き）を自動テストで検証する。
